Нужно написать простой графический редактор BMP файлов на C++ используя только функции WinAPI и g++ v 3.4.5.
Не использовать функции openGL. 
Как можно меньше использовать  сторонние библиотеки.

Функции стандартные.
Слева  в окне панель инструментов с кнопками 32 на 32 пикселя. В каждой кнопке одна буква.
Кнопки расположены по 4 в ряд по горизонтали, 5 - 8 кнопка во втором горизонтальном ряду и т д. При наведении на кнопку появляется подсказка с текстом, обозначающая функцию кнопки. У панели инструментов есть вертикальный скроллбар.

Кнопки панели (Буква кнопки - тултип):
S - Selection. Включает режим прямоугольного выделения.
C - Crop. Обрезает загруженное изображение по выделению инструментом S.
X - Cut. вырезает из исходного загруженного изображения часть, ваыделенную инструментом S. Вырезанная часть может быть потом вставлена в верхний левый угол редактируемого изображения с помощью сочетания клавишь Ctrl+V. Она вставляется в виде интерактивного объекта, который можно перемещать мышью. При потере фокуса (например при клике на исходном изображении вне вставленного фрагмента) рисуется поверх исходного изображения, а интерактивный объект - фрагмент пропадает.
R - Прямоугольник. При  выборе этого инструмента пользователь может рисовать поверх редактируемого изображения прямоугольник, цвет выбирается в палитре, которая будет описана ниже. На панели инструментов появляются две кнопки (ниже основных однобуквенных) в виде черного прямоугольника и белого прямоугольника в черной рамке. При выборе одного из них пользователь может рисовать закрашенные прямоугольники, при выборе другого прозрачные, состоящие из одной только рамки. Еще ниже появляется поле ввода thick для толщины рамки. По умолчанию 2.
E - Эллипс. При  выборе этого инструмента пользователь может рисовать поверх редактируемого изображения эллипс, цвет выбирается в палитре, которая будет описана ниже.  Для эллипса доступны все контролы, описанные для прямоугольника. Работают аналогично.
L - Линия.  При  выборе этого инструмента пользователь может рисовать поверх редактируемого изображения линии, цвет выбирается в палитре, которая будет описана ниже. Для линии доступен инпут thick, описанный для прямоугольника, он задает толщину линии.
+  - Визуально увеличивает масштаб холста на 10%
--(дефис) -  Визуально  уменьшает масштаб холста на 10%

O - открывает диалог выбора bmp, png, jpg файлов. Если пользователь выбирает не bmp файл, создается временный bmp файл путем вызова утилиты `dsgbmp /path/to/file.png /tmp/timestamp.bmp`. Утилита будет реализована отдельно. То же для jpg. Функция также запускается по Ctrl+O

Z - Сохранить отредактированный файл. Если исходный файл был в не bmp формате, содержимое холста сохраняется во временном файле (в том же, который был создан при использовании O), а потом вызывается `dsgbmp /tmp/timestamp.bmp /path/to/file.png`. То же для jpg. Функция также запускается по Ctrl+S

T - ввод текста. Под однобуквенными кнопками  появляется многострочное поле ввода для текста. Текст по умолчанию "Новый текст". Под ним два поля ввода на одной строке с метками перед ними: x [10] y [10]. Под ними два поля ввода на одной строке с метками перед ними: w [70] h [100]. Здесь квадратные скобки подразумевают однострочные поля ввода и их значения по умолчанию. Текст из поля одновременно появляется над редактируемым изображением с координатами x и y из полей ввода и шириной w и h из соответствующих
полей ввода. При изменении значений в полях x y w h текст перемещается над изображением и его рамка изменяет свой размер в соответствии с введенными значениями. при изменении текста в поле ввода текст над редактируемым изображением также изменяется. При нажатии кнопок клавиатуры ARROW_UP и ARROW_DOWN (названия условные, речь о кнопках со стрелками на клавиатуре) значение в одном из полей x y w h изменяется. В том из них, которое в фокусе. При нажатии ARROW_UP инкремент  1, при нажатии ARROW_DOWN декремент  1. Но если одновременно зажата клавиша Shift инкрмент 10 и декремент 10. Для инструмента T доступны две кнопки (ниже основных однобуквенных) в виде черного прямоугольника и белого прямоугольника в черной рамке, ранее описанные для прямоугольника. Выбрав белый прямоугольник в рамке пользователь отключает белый фон у того текста, который отрисован поверх редактируемого изображения, то есть текст отрисовывается поверх редактируемого изображения с координатами x и y. Выбрав черный прямоугольник пользователь включает режим, в котором текст поверх изображения отображается в белом прямоугольнике, то есть поверх редактируемого изображения рисуется белый прямоугольник с координатами верхнего левого угла x y и шириной w  и высотой h, а внутри него выводится текст из поля ввода. Ниже кнопок - прямоугольников появляется кнопка выбора шрифта. Запускает стандартный диалог выбора шрифтов. При выборе шрифт приименяется и к полю ввода и к тексту, отрисованному поверх редактируемого изображения. Пользователь может управлять положением текста поверх изображения и его другими параметрами до тех пор, пока не выберет другой инструмент на панели инструментов. При нажатии Esc текст исчезает и выбирается инструмент S. Если же пользователь не нажимал Esc и выбрал другой инструмент на панели управления, текст поверх редактируемого изображения становится его частью окончательно.

Справа от панели инструментов поле холста. Именно здесь отрисовывается загруженное изображение и здесь ползователь может рисовать испольуюя выбранные инструменты. Есть вертикальный и горизонтальный скроллбары.

Снизу, под панелью инструментов и холстом область палитры. Содержит 16 цветных квадратиков 32 на 32 пикселя (основные цвета палитры). При клике на любом из них к инструментам применяется выбранный цвет. Правее квадрат 48 на 48 пикселей отображает выбранный цвет.  Ещё правее кнопка "More" при нажатии на которую запускается системный диалог выбора цвета.
