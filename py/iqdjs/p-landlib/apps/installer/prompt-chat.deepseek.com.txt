Нужено приложение python3 GTK.

UI (верстка):
Окно приложения фиксированного размера 500 на 356 пикселей.
Рабочая область окна Б расположена от верхней границы окна, размер 
 500 на 315 пикселей.
Левая часть области Б - изображение размером 166 на 315 пикселей.
Расположено в каталоге $X/data/i/nstaller/promo.png, где X - это путь к скрипту 
 installer.py нашего приложения. Приложение должно вычислять $X.
Правая часть области Б представляет собой белый прямоугольник с текстом черным шрифтом.
В приложении должна быть функция (или метод класса) `setText(header, content)` для смены этого текста.
header - это заголовок, text - это текст с поддержкой базового HTML (Теги p, b, i).
Шрифт заголовка HEADER_SIZE пикселей.
Шрифт текста TEXT_SIZE пикселей.
Отступ заголовка от верхней границы области Б 20 пикселей.
Отступ заголовка и текста от левой границы области Б 12 пикселей.

Ниже области Б расположена область кнопок Г, высотой 343 пикселя.
Цвет области Г #ECE9D8.

В области Г есть три кнопки:
"Previous", "Next", "Cancel".
Цвет кнопок #F4F4F0.
Цвет границы кнопок #878FB0.
Цвет текста кнопок черный.
Расстояние от правого края "Cancel" до правой границы окна приложения 14 пикселей.
Расстояние от верхней границы кнопок "Previous", "Next", "Cancel" до верхней границы окна приложения 14 пикселей.
Расстояние между кнопками по горизонтали 15 пикселей.
В приложении должна быть функция (или метод класса) `modBtn(id, text, hide)` для смены текста на кнопке.
Например:
```python
modBtn("p", "Hello")
```
меняет текст кнопки  Previous.
Идентификатор кнопки "Next" - "n".
Идентификатор кнопки "Cancel" - "c".

```python
modBtn("p", "", 0)
```
Не изменяет текст кнопки Previous, но скрывает её.
```python
modBtn("p", "", 1)
```
Не изменяет текст кнопки Previous, но отображает её.

При запуске приложения Previous должна быть скрыта.

В коде приложения должны быть три метода - обработчика нажатия на кнопки
 "Previous", "Next", "Cancel". `onClicPrev`, `onClickNext`, `onClickCancel`.
 
Эти методы должны быть вынесены в начало исходного кода, как можно выше в тексте (но разумеется не ломая работу скрипта).
Цель - легко и просто находить их при модификации скрипта.

Также в начале исходного кода должны быть константы:
```python
HEADER_SIZE = 12
TEXT_SIZE = 12
DEFAULT_HEADER = "Welcome to Your App Setup Wizard"
DEFAULT_TEXT = "<p>This will install YourApp 1.0.0 on your computer</p><p>Click Next to continue or Cancel to exit Setup."
DEFAULT_PREV_TEXT = "Previous"
DEFAULT_NEXT_TEXT = "Next"
DEFAULT_CANCEL_TEXT = "Cancel"
STEP = 0
```

В приложении должен быть метод getUser().
Возвращает имя пользователя, запустившего скрипт (системная переменная $USER).

В приложении должен быть метод getHome().
Возвращает имя пользователя, запустившего скрипт (системная переменная $HOME).

В приложении должен быть метод createDir(path).
Создает указаный каталог. Если промежуточных каталогов нет, создает и их.

В приложении должен быть метод getAppDir() - возвращает путь к каталогу, в котором лежит 
installer.py.

В приложении должен быть метод exec(shellFile, onFinishExecute) - запускает шелл скрипт
 `shellFile`. onFinishExecute должен запуститься, когда работа запущенного скрипта завершена.
Во время работы запущенного скрипта его stdout должен отображаться с помощью `setText(header, content)`
 где header передайтся последний, ранее переданный функции `setText(header, content)`, 
 а content - "Выполняется установка:\n\n" + `последние две строки stdout запускаемого скрипта`.
 
Если текст слишком длинный, размер областей Б и Г не должен изменятся.

Во время работы запущенного скрипта кнопки "Previous", "Next", "Cancel"
disabled.
По завершении они становятся enabled.


В приложении должен быть метод writeFile(filePath, text). Записывает строку в файл.

В приложении должен быть метод readfileFile(filePath). Возвращает контент файла.

В приложении должен быть метод setMainImage(filePath). 
Заменяет изображение, отображаемое в левой части области Б на переданное в `filePath`.

Иконка в окне приложения должна быть из файла 
$X/data/i/nstaller/ico.png
X описан выше.
