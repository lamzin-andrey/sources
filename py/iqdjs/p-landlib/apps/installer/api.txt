app.modBtn("p", "Hello")
Меняет текст кнопки  Previous.
Идентификатор кнопки "Next" - "n".
Идентификатор кнопки "Cancel" - "c".

app.modBtn("p", "", 0)
Не изменяет текст кнопки Previous, но скрывает её.

modBtn("p", "", 1)
Не изменяет текст кнопки Previous, но отображает её.

app.getUser().
Возвращает имя пользователя, запустившего скрипт (системная переменная $USER).

app.getHome().
Возвращает имя пользователя, запустившего скрипт (системная переменная $HOME).

app.createDir(path).
Создает указаный каталог. Если промежуточных каталогов нет, создает и их.

app.getAppDir() - возвращает путь к каталогу, в котором лежит 
installer.py.

app.exec(shellFile, onFinishExecute) - запускает шелл скрипт
 `shellFile`. onFinishExecute должен запуститься, когда работа запущенного скрипта завершена.
Во время работы запущенного скрипта его stdout должен отображаться с помощью `setText(header, content)`
 где header передайтся последний, ранее переданный функции `setText(header, content)`, 
 а content - "Выполняется установка:\n\n" + `последние две строки stdout запускаемого скрипта`.
Имейте ввиду, что onFinishExecute должна быть с одним аргументом, например:

def onFinishInstall(arg1):
    app.modBtn("p", "", 0)
    app.modBtn("c", "Готово")
    app.setText(DEFAULT_HEADER, "<p>Установка завершена</p>")

 
app.writeFile(filePath, text). Записывает строку в файл.

app.readfileFile(filePath). Возвращает контент файла.

app.setMainImage(filePath). 
Заменяет изображение, отображаемое в левой части области Б на переданное в `filePath`.




app.checkLinuxInt()
Возвращает 32 или 64.


app.checkWine32()
Возвращает True если запуск 32 разрядных windows приложений доступен на данном компьютере через wine.


app.checkWine64()
Возвращает True если запуск 64 разрядных windows приложений доступен на данном компьютере через wine.
