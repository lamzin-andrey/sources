О программе Это API позволяет создавать в linux xubuntu десктоп-приложения используя javascript, html и css. Интересовала прежде всего возможность программировать на любом компьютере с linux xubuntu, на котором есть только ОС и больше ничего. Python 3 и PyGtk предустановлены в linux xubuntu (и иногда в linux lubuntu), что позволяет создавать простые приложения, установив только ваш любимый текстовый редактор. API позволяет запускать программы операционной системы Linux Xubuntu, взаимодействовать с файловой системой и некоторыми другим функциями операционных систем, такими как использование системных диалогов. Это позволяет легко создать вам ваше десктоп-приложение. Предназначено это прежде всего для разработчиков, которым надо время от времени быстро написать какую-то GUI утилиту, предназначенную в основном для собственного использования. Разработка программ для широкого круга пользователей также возможна, но вы должны понимать, что надо ориентироваться на последние версии Python, иначе ваши программы могут быть уязвимы из-за отсутствия последних обновлений безопасности.
