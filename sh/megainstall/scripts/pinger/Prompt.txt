Нужна консольная программа на php.
Она будет вызываться раз в час кроном.
Что делает программа.
Она читает файл 
~/.config/lpinger/conf.php

Если файла нет, создаёт его в таком виде
====BOF====
<?php
$domains = [
	'chat.deepseek.com',
	'wkard.ru',
	'vkard.ru',
	'andryuxa.ru',
	'pchat.com.ru',
	'w7z.ru'
];
====EOF====

При запуске программа выполняет с помщью exec()

ping domain -c 4 > /tmp/lpingout.txt 2>/tmp/lpingerr.txt

Парсит /tmp/lpingout.txt и если удалось найти ip в выводе сохраняет их в 

~/.config/lpinger/lastresult.php
примерно в таком виде:
====BOF====
<?php

$data = [
	'wkard.ru' => ['12.12.258.12', '2026-06-20 00:01:00'],
];
====EOF====
Здесь ключ - имя домена, который пинговали. 
В значении первый элемент ip домена, который получили распарсив 
/tmp/lpingout.txt

В значении второй элемент - это время последнего запуска при котором удалост получить ip сервера.

Важно, если не удалось получить ip то данные в массиве для этого домена не обновляются.


Запуск c аругментами:
php /path/to/lpinger.php --help

Выводит:
```txt
1 Создайте файл ~/.config/lpinger/conf.php

2 Заполните его интересующими доменами в таком формате:
====BOF====
<?php
$domains = [
	'chat.deepseek.com',
	'wkard.ru',
	'vkard.ru',
	'andryuxa.ru',
	'pchat.com.ru',
	'w7z.ru'
];
====EOF====

3 Добавьте в кронтаб запуск раз в час
```



php /path/to/lpinger.php --data
Выводит список ip доменов:
```txt
domain		IP				updated time
wkard.ru    12.12.258.12    2026-06-20 00:01:00
```

Запуск без параметров приводит к описанному выше парсингу вывода ping.
